# Globe textures

Vendored locally so the globe renders fully offline (no CDN/network request),
per HACKATHON_PROJECT_PLAN.md Section 11.

- `earth-blue-marble.jpg` — NASA "Blue Marble" Earth surface imagery
  (4096×2048). NASA imagery is in the public domain.
- `earth-topology.png` — grayscale elevation/topology bump map (2048×1024),
  used only to give coastlines subtle relief.

Both are the example textures distributed with the `three-globe` project
(the rendering layer under `react-globe.gl`). They contain no project or
personal data.
