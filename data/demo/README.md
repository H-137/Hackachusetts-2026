# Synthetic demo & parser fixtures

All files here are **synthetic**. They are shaped like AncestryDNA raw-text
exports but contain no real person's genetic data. They exist to exercise the
parser and to drive the offline demo. They must never be described as a real
genome or used to fabricate downstream inference results.

| File | Purpose |
| --- | --- |
| `synthetic_valid.txt` | A valid, header-correct file with enough synthetic autosomal SNPs to pass the inference-sufficiency gate. Drives the demo. |
| `parser_example_four_rows.txt` | The four-row example from the plan. Parses cleanly but is **insufficient** for inference by design (Section 4, rule #9). |
| `no_calls.txt` | Valid file containing `0` no-call encodings. |
| `conflicting_duplicates.txt` | Same rsID/position appearing twice with different genotypes (conflicting) and once identically (exact duplicate). |
| `malformed_records.txt` | Bad column counts, non-integer positions, and an unexpected allele token. |
| `mixed_line_endings.txt` | CRLF + LF mixed, with a leading UTF-8 BOM. |
| `unsupported_chromosomes.txt` | Records on chromosomes 23–26 (X/Y/XY-PAR/MT) that must be counted and excluded. |
| `indels.txt` | AncestryDNA `D`/`I` indel placeholder calls, reported as unsupported. |

`synthetic_valid.txt` is generated by `scripts/make_synthetic_valid.py`. The
others are small, hand-authored, and committed directly.
