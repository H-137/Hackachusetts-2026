# Synthetic demo data

Everything in this directory is **synthetic**. None of it is a real genome or a
real person's data. It exists to develop and demonstrate the explorer fully
offline (HACKATHON_PROJECT_PLAN.md Section 11).

## Files

Parser fixtures (Step 1):

- `parser_example_four_rows.txt` — the four-row example from the plan. Parses
  cleanly but is **insufficient for inference** by design.
- `synthetic_valid.txt` — a small well-formed file.
- `no_calls.txt`, `conflicting_duplicates.txt`, `malformed_records.txt`,
  `mixed_line_endings.txt`, `unsupported_chromosomes.txt`, `indels.txt` — edge
  cases exercised by the parser tests.

Precomputed analysis bundle (Steps 2–6, assumed complete):

- `analysis_bundle.json` — synthetic normalized outputs (ancestry segments,
  variant observations, frequency annotations, disease evidence, one disease
  score) that the integrated explorer renders. Generated by
  `scripts/make_analysis_bundle.py`. Clearly labeled `synthetic: true`.

> The bundle is illustrative. Segment ancestry calls, probabilities, and the
> disease score are fabricated-for-demo values, not inference outputs. They must
> never be presented as a real result.
